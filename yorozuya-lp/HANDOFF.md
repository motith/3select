# 万屋コンサル LP — 引き継ぎメモ

## プロジェクト概要

- サービス名：万屋コンサル（よろずやコンサル）
- 内容：金沢エリアの経営者向けの月額顧問。AI活用・SNS運用・集客導線・採用発信など、「誰に聞けばいいかわからないこと」を何でも相談できる。
- 料金：月額100,000円（税込／税別は未確定）
- 運営：もてぃす（金沢在住）
- LPのゴール：「相談を申し込む」（30分の雑談）へのコンバージョン。サブCTAとして「勉強会・交流会への参加」。

## ファイル

- `yorozuya-lp-v2.html`：現行の最新版。この1ファイルだけで完結している（CSS・JSはインライン、外部依存はGoogle Fontsのみ）。
  - ※ 2026-09-26時点で、このリポジトリにはまだ置かれていない。このディレクトリ（`yorozuya-lp/`）に追加する。
- 過去のPC専用版・スマホ版（v1系）は不採用。参照しない。

## これまでに決まったこと（変えないこと）

- **トーン**：親密感と「気軽に相談できそう」が最優先。権威的・硬い表現は避ける。
- **方言は使わない**：金沢弁は「擦り寄っている感」が強いため不採用。金沢らしさは事実（在住・勉強会開催）と、金箔のさりげない装飾だけで出す。
- **デザインの方向性**：墨×明朝の硬いデザイン（v1）は不採用。現行の「生成り×テラコッタ×藍、丸ゴシック＋手書き風」の路線を維持する。
- **申込みの流れ**：いきなり契約ではなく「フォームかLINEでひと言 → 30分の雑談 → 相性を確かめてから契約」。「合わなければその場で断ってOK」というメッセージを残す。
- **CTAは2種類まで**：メイン「相談を申し込む」、サブ「まずは勉強会に顔を出してみる」。これ以上増やさない。
- **CTA周りのマイクロコピー**：「売り込みはしません」「30分の雑談からでOK」を残す。
- **相談例とチャット**：必ず「イメージです」と明記する（実在の顧客の声ではないため）。
- **統計データ**：中小機構の調査（2026年3月）の数字を使う場合は、出典表記を必ず残す。

## プロフィール・実績の扱い

- YouTube約12万人、TikTok約42万人。**チャンネルのジャンルはLP上に書かない。**
- ストーリーは「塾業界出身 → YouTubeは最初伸びず、改善を重ねて伸び始めた頃に経営者・SNS発信者のコミュニティで動画編集スキルが評価された → 発信とAIの世界へ」という流れ。ジャンル転換の話は書かない。
- 別ブランドの名前は出さない。ウラアカ、胡蝶の鍵などのブランド名・アカウント名は記載しない（実績の中身だけ載せている）。
- 実績は事実のみ。数字の盛り・捏造はしない。未確認のものは［　］のプレースホルダーにする。

## 文体ルール

- ですます調を基本にし、強調したいところだけ体言止めを使う。
- 「〜だ。」で終わる文は威圧的になるので使わない（体言止めにする）。
- 「このページでは〜を紹介します」のようなメタ的な言い回しは入れない。
- 一人称は「僕」（手紙セクションなど、もてぃす本人の言葉の部分）。

## デザイン仕様

- **色**（CSS変数で定義済み）：
  - 背景 `--bg #FBF7F0` / `--bg2 #F4ECDF`
  - 文字 `--ink #2A2622` / `--sub #5C544B`
  - アクセント（テラコッタ） `--accent #A8482A`
  - 藍 `--navy #1F2F45`
  - 金 `--gold #D4AE62`（藍の上でだけ文字色として使う。生成りの上では装飾のみ）
- **フォント**：
  - 見出しは Shippori Mincho B1
  - 本文は Zen Maru Gothic
  - 手書き風（メモ・手紙）は Klee One
- **レスポンシブ**：モバイルファースト。ブレークポイントは720px / 1000px。1000px未満では画面下に固定の相談ボタンを出す。
- **アニメーション**：ヒーローのチャットはメッセージが順番に表示される。スクロールでセクションがふわっと出る（`.rv` クラス＋IntersectionObserver）。`prefers-reduced-motion` に対応済み。
- **タップ領域**：ボタンなどのタップ領域は44px以上を維持する。
